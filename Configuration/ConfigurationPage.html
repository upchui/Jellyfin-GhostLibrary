GhostLibrary Settings

Hide a specific media library from the client home screen and library list while keeping it fully accessible to other plugins (e.g. Cinema Mode) and the file system.

Case-insensitive. Must match the library name exactly as shown in the Jellyfin dashboard (e.g. Trailers). Leave empty to match by ID only.
The library GUID — more reliable than name (survives renames). Find it in the URL when browsing the library in the Jellyfin web UI. Leave empty to match by name only.
